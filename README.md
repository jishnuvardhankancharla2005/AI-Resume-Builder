# AI Resume Builder & ATS Analyzer

An AI-powered Resume Builder and ATS Analyzer that helps users create professional resumes, evaluate resume strength, and improve ATS compatibility using Large Language Models.

This project uses **Ollama with Mistral LLM** for intelligent AI responses and **MongoDB** for storing resume data and analysis history.

---

## Features

- AI-Powered Resume Generation
- ATS Score Analysis
- Resume Strength Evaluation
- Smart Resume Suggestions
- AI-Based Content Improvement
- Professional Resume Formatting
- Resume Data Storage using MongoDB
- Fast Local AI Processing using Ollama
- User-Friendly Interface
- Real-Time Resume Analysis

## How the System Works

1. User enters resume details
2. Resume data is processed and structured
3. ATS analysis engine evaluates resume quality
4. Mistral LLM generates intelligent suggestions
5. The system calculates ATS score and resume strength
6. Resume data and analysis are stored in MongoDB

---

## ATS Score Analysis

The ATS engine checks:

- Resume Structure
- Skills Matching
- Keyword Optimization
- Experience Quality
- Technical Skills
- Resume Readability
- Professional Content Quality
